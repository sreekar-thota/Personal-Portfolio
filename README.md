# Sreekar Thota — Personal Portfolio

An interactive game-inspired developer portfolio featuring a futuristic cyberpunk HUD interface, projects, skills, achievements, animations, and responsive design.

![Portfolio Preview](/public/images/player-avatar.jpg)

## 🎮 Overview

A next-generation developer portfolio crafted with a sci-fi/cyberpunk gaming aesthetic. Built with immersive HUD telemetry, audio-reactive sound effects, interactive skill trees, and interactive mission dossiers.

## ✨ Features

- **Cyberpunk / Game HUD Aesthetic**: Immersive sci-fi UI with glowing borders, scanline overlays, neon accents, and custom animated canvas particles.
- **Interactive Missions (Projects)**: Project dossiers showcasing real-world systems, AI prototypes, and full-stack web platforms:
  - **GestureSnap AI**: Touchless browser-based AI photo booth with real-time hand gesture tracking.
  - **Tennis Auction Platform**: High-stakes real-time sports bidding engine and live league console.
  - **Placement Suite**: AI-powered placement preparation platform with speech analytics and mock interviews.
  - **Agni Netra**: AI-powered aerospace satellite thermal anomaly and industrial fire monitoring system.
  - **InCloudHub**: Student-built all-in-one campus knowledge hub and Cloud Delivery ordering station.
- **Interactive Character Dossier**: RPG-inspired developer stats, attribute proficiencies, and tech stack matrices.
- **Interactive Skill Tree**: Categorized skill nodes with level filters and visual connectivity.
- **Player Journey Timeline**: Level-based progression timeline detailing milestones from origin to production.
- **Audio Feedback System**: Sci-fi sound effects on navigation, hover, and interaction triggers.
- **Custom Cursor & Konami Easter Egg**: Reactive custom crosshair cursor and secret game mode trigger.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays with zero clipping or distortion.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, Vanilla CSS, Custom CSS Variables
- **Animations**: Framer Motion, HTML5 Canvas API
- **Icons**: Lucide React
- **Audio**: Web Audio API / Sound Effects Synthesis

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or later) and **npm** installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sreekar-thota/Personal-Portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Personal-Portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```

6. **Preview production build:**
   ```bash
   npm run preview
   ```
